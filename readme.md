# Проект
## Функционал приложения
На форме **"Авторизация"** имеются поля для ввода Логина и пароля, Capcha, кнопка "Выйти" и кнопка "Войти".
При вводе **user/user** перенаправляет на главную форму. При вводе других данных появляется сообщение об ~~ошибке~~.
На **главной форме** находятся ФИО и номер группы, а также кнопка *"Назад"*.
